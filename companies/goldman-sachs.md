# Goldman Sachs software engineer interview process

Goldman Sachs runs engineers through four stages, commonly over three to six weeks: HackerRank test, recruiter screen, one or two CoderPad screens, then a Superday. The Superday decides the hire. Its three hour-long rounds run on one day, each scored alone, and a weak one can end it early. Associate and VP loops add rounds.
