# Anduril software engineer interview process

Anduril's software engineer loop usually takes three to four weeks: a recruiter call, a live coding screen, then a virtual onsite of roughly four rounds. Commonly that's two coding rounds, an object-modeling or design round and a behavioral run by a senior leader. There's no take-home, and why defense gets asked twice.
