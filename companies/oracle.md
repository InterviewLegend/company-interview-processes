# Oracle software engineer interview process

Oracle's software engineer process runs five stages over about 33 to 41 days by common reports. A recruiter screen comes first, then often a HackerRank test and a phone screen, then four to five onsite rounds ending in the bartender round. Which Oracle org owns the role sets the pace and pay.

| | |
|---|---|
| Stages | 5 stages |
| Timeline | ~33–41 days |
| Online assessment | HackerRank |
