# Rippling software engineer interview process

A Rippling loop runs about three to six weeks: recruiter screen, phone screen, hiring-manager call, then three to five virtual onsite rounds. Even the phone screen wants code that runs. The round that catches people is a build of about ninety minutes, usually an HTTP server or REST API built in your own editor.
