# Morgan Stanley software engineer interview process

Morgan Stanley's software engineer loop usually runs five to six stages over several weeks. Lateral hires open with an 80 to 90 minute HackerRank test; US campus hires take a HireVue video and an SHL test. Three tech rounds and a hiring manager round follow. Core Java and concurrency count for more than hard puzzles.
