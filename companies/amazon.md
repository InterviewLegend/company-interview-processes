# Amazon software engineer interview process

Amazon's SDE process usually takes four to eight weeks, through an online assessment, a phone screen and a Loop of four 55-minute interviews. The OA's two coding problems run on hidden tests in about 70 minutes. Leadership Principles count in every round, and a Bar Raiser from outside the team holds a veto.
