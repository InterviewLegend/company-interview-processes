# Splunk software engineer interview process

A Splunk engineer loop usually takes a few weeks: recruiter call, Karat screen, then four or five onsite rounds. Karat pairs a short quiz with an hour of live work. The onsite holds medium coding, a round where you model classes then code them, behavioral and, from mid level up, a logs and metrics design.
