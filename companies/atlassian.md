# Atlassian software engineer interview process

Atlassian's hiring process has five stages and usually takes four to six weeks, all over video. After the recruiter and a phone screen come four or five virtual rounds: Data Structures, Code Design, system design, a manager talk and a Values Interview. A Hiring Committee then decides the offer and your level together.

|---|---|
| Stages | 5 stages |
| Timeline | ~4–6 weeks |
