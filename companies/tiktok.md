# TikTok software engineer interview process

TikTok's loop usually runs four to five rounds over four to six weeks: recruiter screen, then coding, design, hiring manager and HR rounds. A CodeSignal assessment, when you get one, is the hardest gate: about four problems in 70 to 90 minutes. Rounds run one at a time, so one weak round can end it.
