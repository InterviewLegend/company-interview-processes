# DoorDash software engineer interview process

DoorDash's software engineer loop has five to six stages and usually lasts three to six weeks. A recruiter screen leads to a coding phone screen, most often on HackerRank CodePair. The three or four virtual onsite rounds pair Code Craft, and often Debugging, with coding and design. A roundtable debrief sets hire and level together.

| | |
|---|---|
| Stages | 5–6 stages |
| Timeline | ~3–6 weeks |
