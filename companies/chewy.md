# Chewy software engineer interview process

Chewy's process usually takes two to four weeks, from a 25 to 35 minute recruiter call to a final loop of four one-hour rounds. Between them sits a HackerRank test, two questions in 50 to 90 minutes, or a live screen on some teams. The loop typically covers coding, system design, debugging and behavioral.

| | |
|---|---|
| Stages | ~4 onsite rounds |
| Timeline | 2–4 weeks |
| Online assessment | HackerRank |
