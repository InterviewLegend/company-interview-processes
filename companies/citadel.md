# Citadel software engineer interview process

Citadel's process usually runs five stages in two to four weeks: recruiter call, HackerRank OA, live coding, a Superday and a team match. The OA gives two problems in about 75 minutes, and a timeout counts as a fail. Even correct code can get you cut if a better approach existed.

| | |
|---|---|
| Stages | ~5 stages |
| Timeline | ~2–4 weeks |
| Online assessment | HackerRank |
