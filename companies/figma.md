# Figma software engineer interview process

Figma's loop commonly runs three to four weeks: recruiter screen, hiring-manager call, a 60-minute CoderPad phone screen, then a virtual onsite of about four hours. That onsite covers coding, design rounds built on real-time multiplayer, a behavioral round and a project deep-dive that carries extra weight. Senior loops can add a director screen.
