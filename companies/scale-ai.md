# Scale AI software engineer interview process

Scale AI's software engineer process usually has five to six stages, and a HackerRank build of about fifty minutes decides who reaches the onsite. Then come about four virtual onsite rounds, including a behavioral on the Credos. An all-green test run doesn't guarantee an offer. ML and Research roles add a take-home of several hours.
