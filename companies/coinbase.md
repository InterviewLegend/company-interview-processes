# Coinbase software engineer interview process

Coinbase's software engineer process usually runs six to eight weeks, from a recruiter screen through a 90-minute CodeSignal test to a two-day virtual onsite. The typical senior onsite holds two 90-minute pair-programming rounds, one system design and a 30-minute values round. Most cuts happen in pair-programming, and the hiring manager decides.
