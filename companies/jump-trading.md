# Jump Trading software engineer interview process

Jump Trading's process often takes three to six weeks: recruiter screen, online assessment, one to three phone screens and a superday, usually in Chicago. Reported superday counts run from four to seven rounds. Software candidates get a coding test of roughly 90 to 120 minutes; traders get probability. Teams are often picked after the offer.

| | |
|---|---|
| Stages | ~4–7 Superday rounds |
| Timeline | 3–6 weeks |
