# LinkedIn software engineer interview process

LinkedIn's interview process commonly takes four to eight weeks, from a recruiter call and a CoderPad phone screen to four to six virtual onsite rounds. Nobody runs your code on that screen. A host manager then briefs a hiring committee, which decides hire and level, and team matching follows a pass.
