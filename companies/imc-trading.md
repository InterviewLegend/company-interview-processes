# IMC Trading software engineer interview process

IMC's software engineer loop usually takes four to eight weeks over five to six stages, from a CV screen to a final loop. In between sit a roughly 120-minute HackerRank test, a one-way video and an HR call. The test is only a filter; a working session of up to three hours decides the loop.

| | |
|---|---|
| Stages | 5–6 stages |
| Timeline | ~4–8 weeks |
| Online assessment | HackerRank |
