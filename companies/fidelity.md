# Fidelity software engineer interview process

Fidelity's India campus loop runs in three stages: a HirePro or HackerRank test, a technical round heavy on Java, then HR. US laterals start with a recruiter call and sit one to three interviews of 30 to 45 minutes. The algorithm is usually a single easy-to-medium problem, so offers turn on Java and Spring depth.
