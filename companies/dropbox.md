# Dropbox software engineer interview process

Dropbox's process commonly takes a few weeks over video: a recruiter screen, a proctored CodeSignal test, then about five onsite rounds in two stages. The hour-long CodeSignal test is the first hard gate. The onsite brings coding, a project deep-dive, code review and the All-Around behavioral, plus system design from mid-level up.
