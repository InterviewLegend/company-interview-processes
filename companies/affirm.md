# Affirm software engineer interview process

Affirm's software engineer loop usually takes about two weeks, from a recruiter chat through one or two live coding screens to a virtual onsite. The onsite runs four or five hour-long rounds, and coding fills two even at senior. Prompts are vague on purpose, so ask questions before you type.

| | |
|---|---|
| Stages | 4–5 onsite rounds |
| Timeline | within ~2 weeks |
