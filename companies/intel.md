# Intel software engineer interview process

Intel's software loop usually takes four to eight weeks and ends in three or four back-to-back virtual onsite interviews, then a short manager close. A recruiter call and a C or C++ phone screen come first, plus an online test for new grads. A shaky OS or architecture round can sink a clean coding performance.
