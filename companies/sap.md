# SAP software engineer interview process

Getting hired at SAP usually takes four to six weeks: recruiter screen, HackerRank OA, one to three tech rounds, a techno-managerial round, then HR. The OA pairs two coding problems with 10 to 15 quiz questions, many on Java or C++ output. Strong coders have been cut on fundamentals like virtual functions or SQL indexes.
